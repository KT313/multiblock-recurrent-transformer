`data_preparation/`. These are the *available* pools; the training runs consumed
~5B tokens of them in total (stage token budgets are set in the run configs).

| Source | Examples | Share |
|---|---|---|
| FLAN Collection | 160,000 | 40.0% |

Augmentation: input inversions enabled (5%); CoT and few-shot variants disabled.

verification. Train/val split: 95%/5%.
